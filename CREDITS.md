# Credits

Starhop ships only open-licensed data and images. Every source is listed below with its licence and what it was used for.
The image table at the end lists each of the 210 images individually (object, kind, instrument, author, licence, source page).

## Catalog data

- HYG Database v4.1, David Nash (astronexus) — https://github.com/astronexus/HYG-Database — CC BY-SA 4.0 — star positions, magnitudes, colours, spectral types, distances, names and designations (`stars.json`, `stars-faint.json`).
- d3-celestial, Olaf Frohn — https://github.com/ofrohn/d3-celestial — BSD-3-Clause — constellation names, genitives, label positions, stick figures, IAU boundaries (`constellations.json`) and Milky Way contours (`milkyway.json`).
- OpenNGC, Mattia Verga — https://github.com/mattiaverga/OpenNGC — CC BY-SA 4.0 — NGC/IC/addendum positions, types, magnitudes, sizes, Hubble types, common names (`dsos.json`).
- Wikipedia, "Messier object" (revision 1372398875) — https://en.wikipedia.org/wiki/Messier_object — CC BY-SA 4.0 — distances, article names, type hints and some magnitudes for Messier objects.
- Wikipedia, "Caldwell catalogue" (revision 1383500944) — https://en.wikipedia.org/wiki/Caldwell_catalogue — CC BY-SA 4.0 — Caldwell → NGC/IC mapping, distances, names and some magnitudes for Caldwell objects.
- Wikipedia, "IAU designated constellations by area" (revision 1380319577) — https://en.wikipedia.org/wiki/IAU_designated_constellations_by_area — CC BY-SA 4.0 — cross-check of the constellation area table.
- astronomy-engine, Don Cross — https://github.com/cosinekitty/astronomy — MIT — constellation lookup and B1875 ↔ J2000 rotation in the build.

- International Meteor Organization, *2027 Meteor Shower Calendar*, ed. J. Rendtel, Table 5 "Working list of visual meteor showers" — https://www.imo.net/calendar/ — facts (solar longitude, activity window, radiant, speed, ZHR) for `src/content/showers.json`; cross-checked with Wikipedia "List of meteor showers" (CC BY-SA 4.0), which also supplied parent bodies.
